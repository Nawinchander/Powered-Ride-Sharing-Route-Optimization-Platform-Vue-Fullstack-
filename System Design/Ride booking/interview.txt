Q1. What happens when a user books a ride?

Answer

Validate the user.
Validate pickup and destination.
Create a ride request.
Find nearby available drivers.
Notify the selected driver.
Update the ride status.
Return ride details to the rider.


Q2. Why separate Ride Controller and Ride Service?

Answer

The controller handles HTTP requests and responses, while the service contains business logic. This separation improves readability, testing, and maintainability.

Q4. Why shouldn't business logic be written in routes?

Answer

Routes should only define endpoints. Business logic belongs in services to keep the code modular and reusable.

Q5. How would you prevent duplicate ride requests?

Answer

Use request validation, idempotency keys, or disable the "Book Ride" button until the first request completes.
